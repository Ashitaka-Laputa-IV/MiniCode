Quickstart

一分钟跑起来 Run it in a minute

需要 Python 3.13 和 uv。默认模型是 deepseek:deepseek-flash，也可以通过 --model 切换。

Requires Python 3.13 and uv. The default model is deepseek:deepseek-flash; switch with --model.

安装与运行 Install and run 

git clone https://github.com/Ashitaka-Laputa-IV/MiniCode.git
cd MiniCode
uv sync
uv run minicode "fix the failing test"

REPL 与模型 REPL and models 

# interactive REPL
uv run minicode -i

# OpenCode Go
export OPENCODE_GO_API_KEY="..."
uv run minicode \
  --model opencode-go:deepseek-v4.1-flash \
  "review this change"

提示： CLI 会加载当前目录或祖先目录的 .env，但只应用 MINICODE_MODEL 和已知 provider key；shell 子进程不会继承 provider key。

Note: the CLI loads .env from the current or an ancestor directory, but only applies MINICODE_MODEL and known provider keys; shell subprocesses do not inherit provider keys.

Features

小，但把关键路径做完整 Small, with the important paths covered

不是另一个通用 agent 框架，而是一个可以读懂、可以审查、可以恢复的终端编码循环。

Not another general-purpose agent framework: a terminal coding loop you can read, audit, and resume.

01

三种权限模式 Three permission modes

read-only、ask、yolo 在执行前经过策略判断，危险动作不会悄悄发生。

read-only, ask, and yolo are decided before execution, so risky actions do not happen silently.

02

HITL 审批 Human-in-the-loop

LangGraph interrupt 在写入和风险 shell 前暂停，审批通过后继续同一条消息链。

LangGraph interrupts pause before writes and risky shell commands, then resume the same message thread after approval.

03

检查点与恢复 Checkpoint and resume

REPL 与评测 worker 用 SQLite saver 保存每一步状态；中断、失败或重启后可以回到同一个 thread。

The REPL and eval workers use a SQLite saver for each step; after an interrupt, failure, or restart you can return to the same thread.

04

Shell 护栏 Shell guardrails

allow-list、hard deny-list 和过滤后的环境变量，把 provider key 挡在子进程之外。

Allow-lists, hard deny-lists, and a filtered environment keep provider keys out of child processes.

05

离线评测 Offline evals

smoke、held-out、security、recovery 四个套件，输出 pass@k、token、成本、失败分类和 trace。

Smoke, held-out, security, and recovery suites report pass@k, tokens, cost, failure classes, and traces.

06

Provider 与子智能体 Providers and subagents

默认接 DeepSeek，也支持 OpenCode Go；需要时把任务分给 task 子智能体。

DeepSeek by default, OpenCode Go when you want it, and task subagents when a job should be delegated.

Permissions

先决定，再执行 Decide first, execute second

权限策略是 guardrail，不是 sandbox。不可信任务仍然需要容器或 VM。

Policy is a guardrail, not a sandbox. Untrusted work still belongs in a container or VM.

Architecture

一条清楚的调用链 A traceable call chain

CLI 把任务交给 Deep Agents；策略层包住 shell backend；HITL 和 checkpointer 在旁边守住状态。

The CLI hands work to Deep Agents; a policy layer wraps the shell backend, with HITL and a checkpointer holding the state.

CLI / REPL 解析参数、加载 .env、选择权限模式 Parse args, load .env, choose permission mode
create_deep_agent 系统提示、规划、文件/shell/子智能体工具 System prompt, planning, file/shell/subagent tools
PolicyShellBackend 在 LocalShellBackend 外做策略判断 Policy decisions around LocalShellBackend
Workspace 读写文件、运行命令、返回结果 Read and write files, run commands, return results
HITL approver approve / reject approve / reject
SQLite checkpointer thread 级状态与恢复 Thread-level state and resume
Eval worker 隔离 fixture、隐藏测试、trace Isolated fixtures, hidden tests, traces

Evals

用数字看回归，而不是讲故事 Regression numbers, not a story

两个离线套件、六个基线。样本小、任务由本仓库策划，数字只用于回归跟踪，不是 benchmark 排名或 SOTA 结论。

Two offline suites and six baselines. The samples are small and repository-authored; use the numbers for regression tracking, not as a benchmark ranking or a SOTA claim.

Case study

一个真实的 Link header bug A real Link header bug

从 psf/requests 最小化出来的 fixture：URL 里的逗号被错误拆成两个 Link。

A minimized fixture from psf/requests: a comma inside a URL was split into two bogus links.

上游 issue #2250 和 fix PR #2271 把这个行为改成只在逗号后紧跟 < 时切分。MiniCode 在 minicode-ask 下完成修复，并留下审批和重试记录。

Upstream issue #2250 and fix PR #2271 changed this to split only when a comma is followed by <. MiniCode completed it under minicode-ask, with approvals and a retry on record.

  • 6 审批中断 approvals
  • 50.5s 耗时 wall time
  • 5 隐藏测试通过 hidden tests passed

prompt 已明确建议 re.split(", *<", value)；这里展示的是应用与验证，不是独立发现。 The prompt already suggests re.split(", *<", value); this run applies and verifies it rather than discovering it independently.
