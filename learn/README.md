## 读代码的三个习惯

1. **先看入口，再看实现**：从 `main()`、`build_agent()`、`run_turn()` 往下读，不要从文件第一行开始。
2. **先看测试，再看边界**：一个函数的行为，测试通常比注释更可信；尤其是 `tests/test_policy.py` 和 `tests/test_hitl.py`。
3. **区分三层**：
   - `cli.py`：怎么运行、怎么显示、怎么处理用户输入；
   - `agent.py` / `policy.py` / `backends.py`：运行什么、什么能做、什么不能做；
   - `evals/`：怎么证明它真的能改代码。

## 一句话记住

MiniCode 的重点不是「自己写一个 agent 框架」，而是**用 Deep Agents 拼一个最小可读的 coding agent，并把权限、会话和评测这三件事讲清楚**。
